# Shotgun Party: item card art prompts

22 prompts for generating the item card faces. Paste the **style block** first,
then one card's prompt, so every card comes out in the same style. Ask for
**512 x 736 px** (portrait, about 2:3), and save each one as the file name shown
(e.g. `beer.png`) for `textures/items/`.

## Style block (use with every card)

> A playing-card-sized item card for a dark, gritty retro card game set in a
> smoky back-room saloon. Portrait, 512 x 736 pixels. Chunky early-2000s video
> game look: low-poly, slightly pixelated, PS2-era textures, warm lamp light
> from above, deep shadows. The card has a near-black background
> (#1a1214) with a thin glowing purple border (#8a4fd8) and slightly rounded
> corners. One bold object fills the middle of the card, lit dramatically,
> with a faint purple rim light. Across the bottom is the item's name in big
> chunky pixel-font capitals (cream #f0e6cc with a dark outline), centred. No
> other text, no numbers, no logos, no real brands, no people's faces. Same
> framing, border and lettering on every card so they match as a set.

## Tips

- Generate a few of the same card and pick the one closest in style to the
  rest. If one drifts, say "keep the black card, thin purple border and the
  name in chunky pixel capitals along the bottom, exactly like the others".
- If Gemini adds stray text, ask for "no text except the name at the bottom".
- Keep the name spelled exactly as above: it's what players read in game.
